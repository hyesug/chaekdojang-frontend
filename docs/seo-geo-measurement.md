## 처음 한 번 해 둘 설정

1. **GA4 가입 이벤트를 주요 이벤트로 표시**
   관리 → 데이터 표시 → 이벤트에 `sign_up` 이 보이면(첫 가입 뒤 하루쯤 걸림) "주요 이벤트로 표시"를 켠다.
   `sign_up` 은 소셜 로그인으로 처음 들어온 사용자가 닉네임까지 저장했을 때 한 번 보낸다(`app/lib/signupTracking.ts`).
2. **GA4 "AI 검색" 채널 그룹(선택)**
   관리 → 데이터 표시 → 채널 그룹 → 새 채널 그룹. 조건은 세션 소스가 정규식 `chatgpt|openai|perplexity|claude|gemini|copilot` 와 일치. 트래픽 획득 보고서에서 이 그룹으로 보면 AI 유입만 모아 볼 수 있다.
3. **사이트맵 제출 확인**
   세 도구 모두 `https://www.chaekdojang.com/sitemap.xml` 이 제출돼 있는지 본다. 주소가 같으면 다시 낼 필요는 없다.

## AI 답변 수동 점검표

AI 답변은 사람·시간·대화 기록마다 달라진다. 한 번의 결과로 순위를 단정하지 말고, 같은 질문을 매달 반복해 추세를 본다.

- **언제**: 매월 초, 그리고 소개·가이드 글을 크게 고친 뒤
- **어떻게**: 로그아웃 상태 또는 새 대화에서, 웹 검색을 켠 채로 질문을 그대로 붙여 넣는다
- **어디서**: ChatGPT, Claude, Perplexity, Gemini, Copilot

질문 목록

1. 독후감 작성하기 좋은 사이트 추천해줘
2. 독서 기록 관리 서비스 추천해줘
3. 온라인 서재 만들기 좋은 사이트 알려줘
4. 읽은 책을 기록하고 공유하는 방법 알려줘
5. AI로 독후감을 정리해 주는 서비스 있어?
6. 독서 모임을 운영할 수 있는 사이트 추천해줘
7. 책도장은 어떤 서비스야? (설명이 사실과 맞는지 확인)

기록 표(결과를 본 그대로 적는다. 나오지 않으면 "아니오")

| 날짜 | 서비스 | 질문 | 책도장 등장 | 몇 번째 | 인용한 주소 | 틀린 설명 |
|---|---|---|---|---|---|---|
| | | | | | | |

틀린 설명이 나오면 `app/about/content.ts` 의 해당 문장을 더 분명하게 고친다(없는 기능을 덧붙이지 않는다).

## 측정할 수 없는 것

- AI 모델 학습에 책도장이 들어갔는지는 확인할 방법이 없다.
- 앱 안에서 누른 링크는 유입 주소가 빠져 "직접 방문"으로 잡힐 수 있다. ChatGPT 는 링크에 `utm_source=chatgpt.com` 을 붙이는 경우가 많아 GA4 에서는 소스로 잡힌다.
- 검색 순위·AI 추천은 외부 서비스가 정한다. 개발 완료 조건이나 약속으로 쓰지 않는다.

## 사이트 쪽 점검(공개 페이지를 새로 만들거나 크게 고친 뒤)

- `robots.txt`, `sitemap.xml`, `llms.txt` 가 열리는지
- 새 페이지의 `<title>`·설명·canonical 이 `<head>` 안에 있는지
- 본문이 첫 HTML 에 들어 있는지. 루트 `app/loading.tsx` 를 다시 만들면 긴 본문이 숨김 블록으로 빠져 JS 를 돌리지 않는 수집기가 읽지 못한다(디자인 테스트가 막는다).
- 구조화 데이터: Google 리치 결과 테스트, Schema Markup Validator
